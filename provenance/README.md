# Provenance records

`repository_manifest.json` seals the current upload folder. `figure_inventory.json` maps all six figures to the manuscript and records their original PDF hashes. `package_checks.json` records the checks actually run for this upload.

The result registry and chain-file inventory describe the original saved scientific analyses. The inventory of chain filenames and hashes is retained for traceability; **the chain arrays themselves are not included**.

Other inherited metadata and historical logs record earlier package preparation or environments. Their dates and version labels do not establish a public GitHub/Zenodo release. Current public release and archival DOI completion are not claimed by this folder.
